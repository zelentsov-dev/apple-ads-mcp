# Campaign workflows

## Keyword research

1. Confirm ownership and eligibility for every target storefront.
2. Collect keyword and phrase suggestions for the app.
3. Query search-term popularity for the same markets.
4. If campaigns exist, compare suggestions with search-term and keyword reports.
5. Separate proposed targeting keywords from negative-keyword candidates and show the evidence for each.

## Campaign audit

1. Read campaign, ad group, keyword, and search-term reports for one explicit date range.
2. Read current budgets, bids, statuses, recommendations, and recent change history.
3. Distinguish Apple-provided recommendations from the agent's inference.
4. Report under-spend, expensive terms, irrelevant terms, coverage gaps, and data insufficiency separately.

## Campaign creation

1. Confirm app eligibility, account currency, countries, placement, budget, dates, bid strategy, and desired initial status.
2. Prefer a paused or disabled initial state when Apple accepts it.
3. Preview the campaign, ad group, keywords, negatives, and creative assignment before applying any part.
4. Apply only the receipts that match the authorized plan and re-read each created resource.

## Optimization

Change one decision category at a time: targeting, negatives, bids, budget, creative, or status. Use a comparable report window and preserve the before state. Do not apply Apple's recommendation solely because it exists.
